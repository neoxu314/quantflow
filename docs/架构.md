│                            🎼 编排层                         │
│                                                                                     │
│  功能:                                                                              │
│  • 任务调度引擎      → 循环执行所有任务配置                            │
│  • YAML配置解析      → 解析 tasks.yaml 任务定义                         │
│  • 策略注册表        → 字符串ID映射到策略类                             │

│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │ tasks.yaml 结构:                                                            │   │
│  │ • name        → 任务名称 (如 "A-Stock-Oversold")                            │   │
│  │ • watchlist   → 监控列表路径 (如 "watchlists/a_stocks.yaml")               │   │
│  │ • strategies  → 策略ID列表 (如 ["daily_bull_oversold"])                   │   │
│  │ • output      → 结果输出路径 (如 "output/a_stocks")                        │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │

┌─────────────────────────────────────────────────────────────────────────────────────┐
│                            ⚙️ 执行层                          │
│                                                                                     │
│  功能:                                                                              │
│  • Executor         → 核心引擎：拉数据 → 算指标 → 跑策略 → 存结果                  │
│  • ExecutionJob     → 任务数据结构：股票列表 + 策略列表 + 输出配置                 │
│  • Storage          → JSON结果持久化                                              │
│  • Watchlist        → 监控列表管理                                                │
│                                                                                     │
│  执行流程:                                                                           │
│  1. 遍历股票列表                                                                    │
│  2. 调用 DataSourceFactory.fetch_ohlcv() 拉取行情                                  │
│  3. 调用 IndicatorComposer.compose() 计算指标                                      │
│  4. 调用 Strategy.generate_signals() 生成信号                                      │
│  5. 只检查最新交易日的 buy_signal/sell_signal                                       │
│  6. Storage.save_results() 保存JSON                                                │
│                                                                                     │
│  输出格式: output/{task_name}.json                                                  │
│                                                                                     │
│  文件: execution/executor.py, job.py, storage.py, watchlist.py                     │
