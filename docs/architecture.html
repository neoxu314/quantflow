QuantFlow 早期功能架构图

本图保留早期设计。请查阅 当前架构 和 运行与数据契约。

📱
CLI 入口层
src/quantflow/cli.py
scan 命令
单股扫描分析
  • 指定股票代码 (--code)
  • 指定日期范围 (--start, --end)
  • 选择指标 (--indicator)
monitor 命令
运行单个监控列表
  • 指定 watchlist YAML
  • 指定输出目录
  • 直接调用 Execution 层
tasks 命令
执行编排任务
  • 指定 tasks.yaml 配置
  • 批量处理多个监控任务
  • 调用 Orchestration 层
▼
🎼
编排层 (Orchestration)
src/quantflow/orchestration/
Orchestrator
任务调度引擎，循环执行所有任务配置
  • app.py - 主调度逻辑
  • 遍历 tasks.yaml 中的任务
  • 分发 ExecutionJob 到执行层
TaskConfig
YAML配置解析器
  • loader.py - 解析 tasks.yaml
  • 提取 name/watchlist/strategies/output
Registry
策略注册表
  • registry.py - 字符串ID→类映射
  • "daily_bull_oversold" → Strategy类
  • 支持配置化扩展策略
策略ID 策略类 类型 说明
daily_bull_mid_range DailyBullishMidRangeBuy BUY 多头通道中部买入
daily_bull_oversold DailyBullishOversoldBuy BUY 多头超卖买入
kdj_golden_cross KDJGoldenCrossBuy BUY KDJ金叉买入 (占位)
kdj_dead_cross KDJDeadCrossSell SELL KDJ死叉卖出
dual_line_bear DualLineBearSell SELL 双线空头卖出

⚙️
执行层 (Execution)
src/quantflow/execution/
Executor
核心执行引擎
  • executor.py - 主执行逻辑
  • 拉数据 → 算指标 → 跑策略 → 存结果
  • 只检查最新交易日信号
ExecutionJob
任务数据结构
  • job.py - 任务定义
  • 股票列表 + 策略列表 + 输出配置
Storage
JSON结果持久化
  • storage.py - 结果保存
  • 输出: output/{task_name}.json
Watchlist
监控列表管理
  • watchlist.py - 列表加载
  • 解析 YAML 格式股票清单
1
遍历股票列表 items
2
DataSourceFactory.fetch_ohlcv() 拉取行情数据
3
IndicatorComposer.compose() 计算技术指标
4
Strategy.generate_signals() 生成买卖信号
5
检查 df.iloc[-1] 最新交易日的 buy_signal/sell_signal
6
Storage.save_results() 保存 JSON 结果

策略层 (Strategies)
src/quantflow/strategies/
买入策略
  • DailyBullishMidRangeBuy - 多头通道内回调买入
  • DailyBullishOversoldBuy - 多头区间J<20超卖买入
  • KDJGoldenCrossBuy - KDJ金叉买入 (占位)
卖出策略
  • KDJDeadCrossSell - KDJ死叉卖出
  • DualLineBearSell - 转入空头区间卖出
  • StopLossSell - 止损卖出
组合策略 CompositeStrategy
  • mode="all" - AND逻辑，全部满足
  • mode="any" - OR逻辑，任一满足
📊
指标层 (Indicators)
src/quantflow/indicators/
标准指标
  • KDJ (n=9) → K, D, J, RSV
  • MACD (12,26,9) → MACD, SIGNAL, HIST
  • RSI (14) → RSI值
  • BOLL (20,2) → UPPER, MID, LOWER
  • VOL_MA → VOL_MA5/10/20
自定义指标
  • DualLine - 双线战法多空区间
  • BrickChart - 砖图转换
  • WashoutShortTerm - 洗盘分析
IndicatorComposer
  • 链式计算多指标
  • 输出合并到同一DataFrame
📁
数据层 (Data)
src/quantflow/data/
数据源适配器
  • BaoStock A股免费，qfq复权
  • Tushare A股需Token，基本面
  • YFinance 全球市场 US/HK/JP/KR
  • AKShare 板块分类 EM/THS/SW
支持数据类型
  • OHLCV - 行情数据
  • 基本面 - PE/PB/PS/ROE/市值
  • 板块 - 行业/概念板成分股
DataSourceFactory
  • 主源优先 → 备源兜底
  • 市场自动检测
  • StockCode格式转换

配置层 (Config)
src/quantflow/config/
ConfigLoader
YAML配置加载器
  • loader.py - 解析 quantflow.yaml
  • 默认值管理
  • Token管理 (环境变量/YAML)
市场数据源配置
MarketDataSourceConfig
  • CN: BaoStock → Tushare
  • US/HK/JP/KR: YFinance
  • Sector: AKShare
默认参数
系统默认配置
  • adjust = "qfq" (前复权)
  • period = "d" (日线)
  • logging.level = "INFO"
